JavaScript Variable Declarations

১.  var, let, এবং const-এর প্রধান পার্থক্য
    JavaScript-এ ভ্যারিয়েবল ডিক্লেয়ার করার জন্য এই তিনটি কীওয়ার্ড ব্যবহার করা হয়। তবে এদের কাজ করার নিয়ম ভিন্ন:

    1.  var:
        Function Scope; একই স্কোপে পুনরায় ডিক্লেয়ার করা যায়; মান পরিবর্তন করা যায়; Hoist হয় এবং undefined দিয়ে ইনিশিয়ালাইজ হয়

    2   let:
        Block Scope ({}); পুনরায় ডিক্লেয়ার করা যায় না; মান পরিবর্তন করা যায়; Hoist হয় কিন্তু TDZ-এ থাকে

    3.  const:
        Block Scope ({}); পুনরায় ডিক্লেয়ার করা যায় না; মান পরিবর্তন করা যায় না; Hoist হয় কিন্তু TDZ-এ থাকে
