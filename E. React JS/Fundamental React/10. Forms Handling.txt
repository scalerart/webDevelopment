React-এ Forms Handling শেখা এবং এতে মাস্টার হওয়া অত্যন্ত গুরুত্বপূর্ণ, কারণ প্রায় প্রতিটি রিয়েল-লাইফ প্রজেক্টেই ফর্ম (Login, Registration, Search, Profile Edit) থাকে।

১.  Controlled Components (ইন্ডাস্ট্রি স্ট্যান্ডার্ড & সুপারিশকৃত)
    সংজ্ঞা:
    যে ফর্মে Form Input-এর মানসমূহ সরাসরি React State (useState) দ্বারা নিয়ন্ত্রিত হয়, তাকে Controlled Component বলে।

    ইনপুটের value যুক্ত থাকে React State-এর সাথে এবং প্রতিটি কি-স্ট্রোক বা ইনপুট পরিবর্তনে onChange ইভেন্টের মাধ্যমে State আপডেট হয়।

    =>  রিয়েল প্রজেক্ট উদাহরণ: Complex Multi-input Form
        JavaScript
        import React, { useState } from 'react';

        export function RegistrationForm() {
            // একটি অবজেক্টে পুরো ফর্মের স্টেট হ্যান্ডেল করা
            const [formData, setFormData] = useState({
                username: '',
                email: '',
                role: 'user',
                agreeToTerms: false,
            });

            const handleChange = (e) => {
                const { name, value, type, checked } = e.target;

                setFormData(prev => ({
                ...prev,
                [name]: type === 'checkbox' ? checked : value // Dynamic Property Key
                }));
            };

            const handleSubmit = (e) => {
                e.preventDefault(); // পেজ রিলোড আটকানো
                console.log('Submitted Data:', formData);
            };

            return (
                <form onSubmit={handleSubmit}>
                <input
                    type="text"
                    name="username"
                    value={formData.username}
                    onChange={handleChange}
                    placeholder="Username"
                />

                <input
                    type="email"
                    name="email"
                    value={formData.email}
                    onChange={handleChange}
                    placeholder="Email"
                />

                <select name="role" value={formData.role} onChange={handleChange}>
                    <option value="user">User</option>
                    <option value="admin">Admin</option>
                </select>

                <label>
                    <input
                    type="checkbox"
                    name="agreeToTerms"
                    checked={formData.agreeToTerms}
                    onChange={handleChange}
                    />
                    Agree to terms
                </label>

                <button type="submit">Register</button>
                </form>
            );
        }

২.  Uncontrolled Components (useRef)
    সংজ্ঞা:
    যে ফর্মে Form Input-এর মান সরাসরি DOM Node (DOM নিজেই) মেইনটেইন করে এবং React State ব্যবহার করা হয় না, তাকে Uncontrolled Component বলে।

    এখানে ইনপুটের মান বের করার জন্য useRef ব্যবহার করা হয়।

    উদাহরণ:
    JavaScript
    import React, { useRef } from 'react';

    export function QuickLoginForm() {
        const emailRef = useRef(null);
        const passwordRef = useRef(null);

        const handleSubmit = (e) => {
            e.preventDefault();
            // রি-রেন্ডার ছাড়া সরাসরি DOM থেকে মান নেওয়া
            console.log('Email:', emailRef.current.value);
            console.log('Password:', passwordRef.current.value);
        };

        return (
            <form onSubmit={handleSubmit}>
            <input ref={emailRef} type="email" placeholder="Email" />
            <input ref={passwordRef} type="password" placeholder="Password" />
            <button type="submit">Login</button>
            </form>
        );
    }

    ৪.  Best Used For
        "৯৫% রিয়েল-লাইফ ফর্ম, ডায়নামিক ইনপুট, সোশ্যাল ইনপুট।"
        "বিশাল ফর্ম যেখানে পারফরম্যান্স ইস্যুতে স্টেট কমানো দরকার, File Uploads (<input type=""file"" />)।"

    =>  গুরুত্বপূর্ণ নোট:
        File Input (<input type="file" />) সবসময় Uncontrolled Component হতে বাধ্য, কারণ ব্রাউজারের সিকিউরিটি পলিসির কারণে ফাইল ইনপুটের value প্রপার্টি প্রোগ্রাম্যাটিকালি সেট করা যায় না।


৪.  Custom Validation Logic (Vanilla React Validation)
    কোনো লাইব্রেরি ছাড়া ম্যানুয়ালি স্টেট দিয়ে ইনপুট ভ্যালিডেশন করার স্ট্যান্ডার্ড উপায়:

    JavaScript
    import React, { useState } from 'react';

    export function ValidatedInput() {
        const [email, setEmail] = useState('');
        const [error, setError] = useState('');

        const handleEmailChange = (e) => {
            const val = e.target.value;
            setEmail(val);

            if (!val.includes('@')) {
            setError('Invalid email address');
            } else {
            setError('');
            }
        };

        return (
            <div>
            <input type="email" value={email} onChange={handleEmailChange} />
            {error && <p style={{ color: 'red' }}>{error}</p>}
            </div>
        );
    }

৫.  প্রোডাকশন লাইব্রেরিস (React Hook Form & Zod)
    বড় রিয়েল-লাইফ প্রজেক্টে ম্যানুয়ালি স্টেট সামলাতে গেলে বয়লারপ্লেট কোড অনেক বেড়ে যায় এবং পারফরম্যান্স ইস্যু হতে পারে। তাই ইন্ডাস্ট্রিতে প্রোডাকশন ফর্মে React Hook Form এবং Schema Validation-এর জন্য Zod বা Yup ব্যবহার করা হয়।

    React Hook Form-এর সুবিধা:
    1.  Uncontrolled under the hood: টাইপ করার সময় অহেতুক পুরো ফর্ম Re-render করায় না (অসাধারণ পারফরম্যান্স)।
    2.  কম কোড (Minimal Boilerplate): স্টেট এবং অন-চেঞ্জ হ্যান্ডলার নিজে লেখার দরকার পড়ে না।

    JavaScript
    // React Hook Form-এর সংক্ষিপ্ত ঝলক
    import { useForm } from 'react-hook-form';

    export function RHFExample() {
        const { register, handleSubmit, formState: { errors } } = useForm();

        const onSubmit = (data) => console.log(data);

        return (
            <form onSubmit={handleSubmit(onSubmit)}>
            <input {...register('username', { required: 'Username is required' })} />
            {errors.username && <p>{errors.username.message}</p>}

            <button type="submit">Submit</button>
            </form>
        );
    }

৬.  ইন্টারভিউ প্রশ্ন ও স্মার্ট উত্তর (Interview Q&A)
    ১.  React-এ "Uncontrolled to Controlled input error" কেন হয় এবং কীভাবে সমাধান করবে?
        উত্তর:

        যখন কোনো ইনপুটের প্রাথমিক value স্টেট হিসেব করে undefined বা null পাস করা হয়, React ধরে নেয় এটি একটি Uncontrolled Component। পরবর্তীতে যখন ওই স্টেটে কোনো মান দেওয়া হয় (যেমন String), তখন React ওয়ার্নিং দেয়: "A component is changing an uncontrolled input to be controlled"\।

        সমাধান: Initial State হিসেবে সবসময় অন্তত একটি খালি স্ট্রিং "" দেওয়া নিশ্চিত করতে হবে।

    ২.  Controlled vs Uncontrolled Components:
        "Controlled Components keep input values synchronized within the React state, rendering on every keystroke. This allows for real-time validation and dynamic UI behavior.

        Uncontrolled Components rely on the native DOM to store form data, which is retrieved using useRef. They avoid frequent re-renders and are preferred for non-standard inputs like file uploads or performance-heavy forms."
