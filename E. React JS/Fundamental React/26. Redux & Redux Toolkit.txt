Redux হলো JavaScript অ্যাপ্লিকেশনের জন্য একটি Predictable (ভবিষ্যদ্বাণীযোগ্য) Centralized State Management লাইব্রেরি। পূর্বে প্রচুর বয়লারপ্লেট কোডের কারণে রেডাক্স লেখা জটিল হলেও, বর্তমানে Redux Toolkit (RTK) হলো রেডাক্স ব্যবহারের অফিসিয়াল এবং ইন্ডাস্ট্রি স্ট্যান্ডার্ড পদ্ধতি।

প্রফেশনাল প্রজেক্টের জন্য Redux & Redux Toolkit-এর বিস্তারিত গাইড নিচে সাজিয়ে দেওয়া হলো:

১.  Redux-এর ৩টি মৌলিক নীতি (3 Core Principles)
    1.  Single Source of Truth:
        পুরো অ্যাপ্লিকেশনের গ্লোবাল স্টেট একটিমাত্র অবজেক্ট হিসেবে মূল Store-এর ভেতরে থাকে।

    2.  State is Read-Only:
        স্টেট সরাসরি পরিবর্তন করা যায় না। স্টেট আপডেট করতে হলে একটি Action (কী ঘটেছে তার বর্ণনা) Dispatch করতে হয়।

    3.  Changes are made with Pure Functions:
        স্টেট কীভাবে পরিবর্তন হবে তা নির্ধারণ করে Reducers (যা আগের স্টেট এবং অ্যাকশন নিয়ে সম্পূর্ণ নতুন একটি স্টেট রিটার্ন করে)।

২.  Classic Redux vs Redux Toolkit (RTK)
    0.  বিষয়
        Classic Redux (Legacy)
        Redux Toolkit - RTK (Modern Standard)

    1.  Setup & Config
        "createStore, middleware, devtools আলাদা কনফিগার করতে হতো।"
        configureStore() দিয়ে ১ লাইনে অটো-কনফিগার হয়ে যায়।

    3.  Boilerplate Code
        "Actions, Constants, Reducers আলাদা ফাইলে প্রচুর কোড লিখতে হতো।"
        createSlice() দিয়ে অ্যাকশন ও রিডিউসার একসাথে লেখা যায়।

    4.  Immutability
        স্প্রেড অপারেটর (...state) দিয়ে সাবধানে ইমিউটেবল কোড লিখতে হতো।
        "Immer.js বিল্ট-ইন থাকে, তাই মুটেবল (Direct State Mutation) কোড লিখলেও তা নিরাপদে হ্যান্ডেল হয়।"

৩.  RTK-এর ডেটা ফ্লো (Architecture & Data Flow)
    Plaintext
    [UI Component] ──(dispatch)──> [Action] ──> [Reducer (Slice)] ──> [Update Store] ──> [UI Re-renders via useSelector]

৪.  Redux Toolkit বাস্তবায়নের কমপ্লিট কোড (Step-by-Step)
    1.  Slice তৈরি করা (src/features/counter/counterSlice.js)
        JavaScript
        import { createSlice } from '@reduxjs/toolkit';

        const initialState = { value: 0 };

        export const counterSlice = createSlice({
          name: 'counter',
          initialState,
          reducers: {
            increment: (state) => {
              // Immer-এর কারণে সরাসরি মিউটেট করার মতো কোড লেখা যায়
              state.value += 1;
            },
            decrement: (state) => {
              state.value -= 1;
            },
            incrementByAmount: (state, action) => {
              state.value += action.payload;
            },
          },
        });

        // Action creators স্বয়ংক্রিয়ভাবে তৈরি হয়
        export const { increment, decrement, incrementByAmount } = counterSlice.actions;
        export default counterSlice.reducer;

    2.  Store কনফিগার করা (src/app/store.js)
        JavaScript
        import { configureStore } from '@reduxjs/toolkit';
        import counterReducer from '../features/counter/counterSlice';

        export const store = configureStore({
          reducer: {
            counter: counterReducer, // একাধিক রিডিউসার এখানে যোগ করা যায়
          },
        });

    3.  অ্যাপকে Provider দিয়ে র‍্যাপ করা (src/main.jsx)
        JavaScript
        import React from 'react';
        import ReactDOM from 'react-dom/client';
        import { Provider } from 'react-redux';
        import { store } from './app/store';
        import App from './App';

        ReactDOM.createRoot(document.getElementById('root')).render(
          <Provider store={store}>
            <App />
          </Provider>
        );

    4.  কম্পোনেন্টে ব্যবহার করা (src/components/Counter.jsx)
        JavaScript
        import React from 'react';
        import { useSelector, useDispatch } from 'react-redux';
        import { increment, decrement, incrementByAmount } from '../features/counter/counterSlice';

        export function Counter() {
          // Store থেকে স্টেট পড়ার জন্য useSelector
          const count = useSelector((state) => state.counter.value);
          // Action ট্রিগার করার জন্য useDispatch
          const dispatch = useDispatch();

          return (
            <div>
              <h1>Count: {count}</h1>
              <button onClick={() => dispatch(increment())}>+</button>
              <button onClick={() => dispatch(decrement())}>-</button>
              <button onClick={() => dispatch(incrementByAmount(5))}>+5</button>
            </div>
          );
        }

৫.  Async Logic & API Calling: createAsyncThunk
    ব্যাকএন্ড থেকে ডেটা আনার (Asynchronous API Call) জন্য RTK-তে createAsyncThunk ব্যবহার করা হয়:

    JavaScript
    import { createSlice, createAsyncThunk } from '@reduxjs/toolkit';

    // Async Thunk Action
    export const fetchUsers = createAsyncThunk('users/fetchUsers', async () => {
      const response = await fetch('https://jsonplaceholder.typicode.com/users');
      return response.json();
    });

    const userSlice = createSlice({
      name: 'users',
      initialState: { data: [], loading: false, error: null },
      reducers: {},
      extraReducers: (builder) => {
        builder
          .addCase(fetchUsers.pending, (state) => {
            state.loading = true;
          })
          .addCase(fetchUsers.fulfilled, (state, action) => {
            state.loading = false;
            state.data = action.payload;
          })
          .addCase(fetchUsers.rejected, (state, action) => {
            state.loading = false;
            state.error = action.error.message;
          });
      },
    });

    export default userSlice.reducer;

৬.  Questions & Answer
    ১.  RTK-তে সরাসরি state.value += 1 লিখলে Immutability কীভাবে বজায় থাকে?
        উত্তর:

        Redux Toolkit-এর ভেতরে ব্যাকগ্রাউন্ডে Immer.js লাইব্রেরি কাজ করে। Immer আমাদের লেখার সুবিধার্থে Mutable Syntax লিখতে দেয়, কিন্তু ব্যাকগ্রাউন্ডে এটি স্টেটের একটি ডুপ্লিকেট কপি (Draft State) তৈরি করে নিরাপদে একটি সম্পূর্ণ নতুন Immutable State তৈরি করে দেয়।

    ২.  Redux & Redux Toolkit:
        "Redux is a centralized state management library based on three core principles: a single source of truth, read-only state, and changes made via pure functions called reducers.

        Modern Redux applications use Redux Toolkit (RTK) to eliminate boilerplate code. RTK simplifies setup using configureStore, combines actions and reducers using createSlice, leverages Immer.js for immutable updates, and handles async API calls smoothly using createAsyncThunk or RTK Query."
