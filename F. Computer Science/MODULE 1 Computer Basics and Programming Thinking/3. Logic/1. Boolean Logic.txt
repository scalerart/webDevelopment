1.  Boolean Logic

P1: Computer কীভাবে সিদ্ধান্ত নেয়? (Story Style)
    ভাবো তুমি বাসা থেকে বের হবে।

    তোমার নিয়ম:
        1.  যদি বৃষ্টি হয় AND ছাতা থাকে → বের হবে
        2.  যদি বৃষ্টি না হয় OR গাড়ি থাকে → বের হবে

    এখানে তুমি আসলে Logic ব্যবহার করছো।

    Computer-ও ঠিক এভাবেই সিদ্ধান্ত নেয়।
    কিন্তু Computer শুধু দুইটা জিনিস বোঝে:
        1.  True  / False
        2.  1     / 0

    ✔ এই সিদ্ধান্ত নেওয়ার নিয়মকে বলে → Boolean Logic

P2: Boolean Logic কী?
    Boolean Logic হলো এমন একটি Logic System যেখানে—

    1.  ফলাফল শুধু দুইটা হয়
        1.  True (1)
        2.  False (0)

    2.  Logical operation ব্যবহার করে সিদ্ধান্ত নেওয়া হয়

    ✔ মূল কথা: Boolean Logic = Computer-এর সিদ্ধান্ত নেওয়ার ভাষা

P3: Boolean Value (Foundation)
    Boolean-এর মাত্র দুইটা value: 0, 1

P4: Boolean Operations (Core Concept)
    1.  AND (সব সত্য হলে সত্য)
        Rule:
            1.  1 AND 1 = 1
            2.  বাকি সব = 0

        উদাহরণ:
            পাস AND উপস্থিত
            দুইটাই সত্য হলে কাজ হবে।

    2.  OR (একটা সত্য হলেই সত্য)
        Rule:
            1.  0 OR 0 = 0
            2.  বাকি সব = 1

        উদাহরণ: বাস OR বাইক থাকলে যাবে

    3.  NOT (উল্টো করে)
        Rule:
            1.  NOT 1 = 0
            2.  NOT 0 = 1

        উদাহরণ:
            NOT Rain
            বৃষ্টি না হওয়া।            

P5: Boolean Expression
    Expression মানে Logical statement।

    উদাহরণ: (A AND B)

    যদি:
        A = 1
        B = 0

    তাহলে:
        Output = 0

P6: Boolean Logic Computer-এ কোথায় ব্যবহার হয়?
    Boolean Logic ছাড়া Computer কাজই করতে পারে না।

    ব্যবহার হয়:
        1.  CPU Decision Making
        2.  Digital Circuit
        3.  Conditional Statement
        4.  Search Engine
        5.  Database Query

    উদাহরণ:
        if (age > 18)

    ✔  এখানেও Boolean।

P7: Real-Life Examples
    Situation	            Logic
    Login + Password	    AND
    WiFi অথবা Mobile Data  OR
    Light OFF	            NOT

P8: কেন Boolean Logic লাগে?
    কারণ Computer-কে সিদ্ধান্ত নিতে হয়:

    ✔  Yes / No
    ✔  True / False
    ✔  ON / OFF

    তাই Boolean হলো Computer-এর চিন্তার ভিত্তি।

=>  Practice Task
    1.  Boolean Logic কী?
        বুলিয়ান লজিক হলো এমন একটি গাণিতিক সিস্টেম যা শুধুমাত্র দুটি মান নিয়ে কাজ করে: ১ (True/সত্য) এবং ০ (False/মিথ্যা)। এই লজিকের মূল ভিত্তি হলো লজিক্যাল অপারেটর (যেমন: AND, OR, NOT), যা বিভিন্ন ইনপুট থেকে একটি নির্দিষ্ট আউটপুট তৈরি করে।

        সহজ কথায়, কম্পিউটার যখনই কোনো সিদ্ধান্ত নেয় (যেমন: পাসওয়ার্ড কি সঠিক?), তখন সে বুলিয়ান লজিক ব্যবহার করে যাচাই করে যে বিষয়টি সত্য না মিথ্যা।

    2.  Output বের করো: 1 AND 0
        AND লজিকের নিয়ম: এর আউটপুট তখনই '১' (সত্য) হবে যদি সবগুলো ইনপুট '১' হয়। যদি একটিও '০' থাকে, তবে আউটপুট '০' হবে।

            1.  ইনপুট ১: ১
            2.  ইনপুট ২: ০
            3.  আউটপুট: ০ (False)

        উদাহরণ: ধরো, একটি ভবনে ঢোকার শর্ত হলো—তোমার কাছে 'আইডি কার্ড' (১) থাকতে হবে এবং 'পারমিশন' (১) থাকতে হবে। তোমার কাছে আইডি কার্ড আছে (১), কিন্তু পারমিশন নেই (০)। যেহেতু তুমি একটি শর্ত পূরণ করতে পারোনি, তাই লজিক্যাল আউটপুট হবে '০' (তুমি ঢুকতে পারবে না)।

    3.  Output বের করো: NOT(1)
        NOT লজিকের নিয়ম: এটি একটি ইনভার্টার বা উল্টানো লজিক। এটি যা ইনপুট পায়, তার উল্টোটি আউটপুট হিসেবে দেয়।

            1.  ইনপুট: ১
            2.  আউটপুট: ০ (False)

        উদাহরণ: ধরো, একটি লাইটের সুইচের লজিক হলো 'NOT'। তুমি যদি সুইচ অন করো (১), লাইটটি অফ হয়ে যাবে (০)। এটি ইনপুটকে সবসময় উল্টে দেয়।

    4.  কেন Computer Boolean ব্যবহার করে?
        এর পেছনে মূল তিনটি কারণ রয়েছে:

        ১.  ইলেকট্রনিক্সের সাথে সামঞ্জস্য:
            কম্পিউটারের ভেতরের ট্রানজিস্টরগুলো মূলত ছোট ছোট ইলেকট্রিক সুইচ। বিদ্যুৎ প্রবাহিত হওয়াকে আমরা '১' এবং বিদ্যুৎ না থাকাকে '০' ধরি। বুলিয়ান লজিক এই অন-অফ অবস্থার সাথেই নিখুঁতভাবে কাজ করে।

        ২.  সিদ্ধান্ত গ্রহণের গতি:
            কম্পিউটার সেকেন্ডে কোটি কোটি লজিক্যাল অপারেশন করতে পারে। বুলিয়ান লজিক ব্যবহারের ফলে হার্ডওয়্যার খুব দ্রুত সিদ্ধান্ত নিতে পারে—যেমন: "যদি এই সংখ্যাটি ১০-এর বড় হয়, তবে এটি করো।"

        ৩.  জটিল ডিজাইনের সহজ সমাধান:
            কোটি কোটি ট্রানজিস্টর দিয়ে তৈরি একটি আধুনিক প্রসেসর ডিজাইন করা অসম্ভব হতো যদি আমাদের বুলিয়ান লজিকের মতো গাণিতিক পদ্ধতি না থাকতো। এটি প্রকৌশলীদের জটিল সার্কিটকে সরল এবং সুশৃঙ্খল করতে সাহায্য করে।
