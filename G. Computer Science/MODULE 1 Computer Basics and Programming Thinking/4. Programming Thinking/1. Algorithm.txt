1.  Algorithm

P1: Programming করার আগে কী করতে হয়? (Story Style)
    ভাবো তুমি চা বানাবে

    তুমি কী করবে?
        1.  পানি গরম করবে
        2.  চা পাতা দিবে
        3.  চিনি দিবে
        4.  পরিবেশন করবে

    যদি এলোমেলো করো—ভালো চা হবে না।
    অর্থাৎ কাজ করার আগে ধাপে ধাপে পরিকল্পনা লাগে।

    ✔  Programming-এ এই ধাপে ধাপে পরিকল্পনাকেই বলে → Algorithm

P2: Algorithm কী?
    Algorithm হলো কোনো সমস্যা সমাধানের জন্য Step-by-step সুনির্দিষ্ট নির্দেশনা (Instructions)।

    অর্থাৎ—
        Problem ↓ Steps ↓ Solution

    ✔  মূল কথা:
        Algorithm = Problem solve করার recipe

P3: Algorithm-এর বৈশিষ্ট্য (Important)
    একটা ভালো Algorithm-এর সাধারণত এই বৈশিষ্ট্য থাকে:

    1.  Input
        কিছু data নিতে পারে

        উদাহরণ:
            a = 5
            b = 3

    2.  Output
        একটা ফলাফল দিবে

        উদাহরণ:
            8

    3.  Definiteness
        প্রতিটি Step পরিষ্কার হবে

        ✔  “দুইটা সংখ্যা যোগ করো”

    4.  Finiteness
        একসময় শেষ হতে হবে
        Infinite চলতে পারবে না।

    5.  Effectiveness
        বাস্তবে করা সম্ভব হতে হবে।

P4: Algorithm কীভাবে লিখে?
    সাধারণ Structure:
        Start
        Step 1
        Step 2
        Step 3
        Stop

    উদাহরণ:
        দুইটা সংখ্যা যোগ করার Algorithm

        Start
        Input A
        Input B
        Sum = A + B
        Output Sum
        Stop

P5: Algorithm Example (Core Concept)    
    সমস্যা:
    দুইটা সংখ্যার মধ্যে বড় সংখ্যা বের করো।

    Algorithm:
        Start
        Input A
        Input B

        If A > B
            Print A

        Else
            Print B

        Stop

P6: Algorithm vs Program
    বিষয়	        Algorithm	        Program
    কী	            পরিকল্পনা	        বাস্তব Code
    Language	    সাধারণ ভাষা	        Programming Language
    Execute	        হয় না	            হয়

    উদাহরণ:
        Recipe → Algorithm
        Cooking → Program

=>  Practice Task
    1.  Algorithm কী?
        অ্যালগরিদম হলো কোনো নির্দিষ্ট সমস্যা সমাধানের জন্য ধাপে ধাপে অনুসরণ করা কতগুলো নিয়ম বা নির্দেশাবলী। সহজ কথায়, একটি কাজ কীভাবে সম্পন্ন হবে তার একটি সুনির্দিষ্ট রূপরেখা।

        উদাহরণ হিসেবে ভাবো, চা বানানোর অ্যালগরিদম:
            ১.  চুলায় পানি গরম করো।
            ২.  তাতে চা পাতা দাও।
            ৩.  পরিমাণমতো চিনি ও দুধ মেশাও।
            ৪.  কিছুক্ষণ ফুটিয়ে কাপে ঢাল।
            ৫.  চা প্রস্তুত।

        ঠিক একইভাবে, কম্পিউটারের কাছে কোনো কাজ করানোর আগে আমাদের এমন ধাপগুলো লিখে নিতে হয়।

    2.  Algorithm লিখো: দুইটা সংখ্যা গুণ করো।
        যেকোনো দুটি সংখ্যা গুণ করার জন্য আমাদের একটি সাধারণ অ্যালগরিদম নিচে দেওয়া হলো:
        ধাপ ১: শুরু করো।
        ধাপ ২: ব্যবহারকারীর কাছ থেকে প্রথম সংখ্যাটি (A) নাও।
        ধাপ ৩: ব্যবহারকারীর কাছ থেকে দ্বিতীয় সংখ্যাটি (B) নাও।
        ধাপ ৪: সংখ্যা দুটির গুণফল বের করো (Result = A X B)।
        ধাপ ৫: গুণফলটি (Result) প্রদর্শন করো।
        ধাপ ৬: শেষ করো।

    3.  Algorithm লিখো: একটা সংখ্যা Positive না Negative বের করো।
        ধাপ ১: শুরু করো।
        ধাপ ২: ব্যবহারকারীর কাছ থেকে সংখ্যাটি (N) ইনপুট নাও।
        ধাপ ৩: যদি সংখ্যাটি N > 0 হয়, তবে প্রদর্শন করো যে "সংখ্যাটি Positive"।
        ধাপ ৪: যদি সংখ্যাটি N < 0 হয়, তবে প্রদর্শন করো যে "সংখ্যাটি Negative"।
        ধাপ ৫: যদি সংখ্যাটি 0 হয়, তবে প্রদর্শন করো যে "সংখ্যাটি শূন্য"।
        ধাপ ৬: শেষ করো।

    4.  Algorithm আর Program-এর পার্থক্য বলো।
        অনেকেই এই দুটিকে গুলিয়ে ফেলে, কিন্তু তাদের মধ্যে মৌলিক পার্থক্য আছে:
            ১.  সংজ্ঞা
                সমস্যা সমাধানের যৌক্তিক ধাপ। অ্যালগরিদম (Algorithm)
                কম্পিউটারে রান করার জন্য লেখা কোড। প্রোগ্রাম (Program)

            ২.  প্রকাশ
                এটি সাধারণ ভাষায় (Human language) লেখা হয়। অ্যালগরিদম (Algorithm)
                এটি নির্দিষ্ট প্রোগ্রামিং ভাষায় (Python/C++/Java) লেখা হয়। প্রোগ্রাম (Program)

            ৩.  নির্ভরশীলতা
                এটি কোনো নির্দিষ্ট ভাষার ওপর নির্ভর করে না। অ্যালগরিদম (Algorithm)
                এটি নির্দিষ্ট কম্পাইলার বা ইন্টারপ্রেটারের ওপর নির্ভরশীল। প্রোগ্রাম (Program)

            ৪.  উদ্দেশ্য
                লজিক বা পরিকল্পনা তৈরি করা। অ্যালগরিদম (Algorithm)
                পরিকল্পনাটি কম্পিউটারের মাধ্যমে বাস্তবায়ন করা। প্রোগ্রাম (Program)
        
        সহজ মনে রাখার উপায়: অ্যালগরিদম হলো রান্নার রেসিপি, আর প্রোগ্রাম হলো সেই রেসিপি অনুযায়ী রান্না করা খাবার যা কম্পিউটার সরাসরি "খেতে" বা বুঝতে পারে।
